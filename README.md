# Sistema de Desconto Progressivo 🛍️

Projeto em Python desenvolvido para a atividade da **Agenda 6 - DS I**, simulando o sistema de descontos de uma loja online.

## 📋 Regras de Desconto
* **Compras abaixo de R$ 200,00:** 5% de desconto.
* **Compras entre R$ 200,00 e R$ 299,99:** 10% de desconto.
* **Compras a partir de R$ 300,00:** 15% de desconto.
